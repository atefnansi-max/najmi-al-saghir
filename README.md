# ⭐ نجمي الصغير

موقع للمعلمة بيحوّل كل لحظة حلوة لطفل بالروضة لصورة بطولية ملوّنة، وبتنبعت لأهله على واتساب بكبسة.

الخطة والأفكار الكاملة: [docs/ideas/najmi-al-saghir.md](docs/ideas/najmi-al-saghir.md)

## التشغيل على الكمبيوتر

```bash
python -m http.server 5173 --directory web
```

بعدين افتحي: http://localhost:5173

## شو في بالنسخة الأولى
- **صفّي:** صور الطلاب، ودائرة صفرا منقّطة للطفل اللي ما أخد نجمة هالأسبوع (عدّاد العدالة)
- **طفل جديد:** اسم، ولد أو بنت، رقم واتساب الأهل، موافقة الأهل، وصورة بتنقصّ تلقائياً (قصّ ذكي أو دائرة)
- **اعملي نجمة:** المايك (لهجة أردنية) أو الكتابة، أو 8 أزرار سلوك، و12 مشهد جاهز، و5 زينات، وجمل تشجيع أردنية بالمذكر والمؤنث
- **🪄 مشهد من وصفك:** بيرسم خلفية جديدة من الوصف (تجريبي، بيبعت الوصف بس لموقع Pollinations، بلا أسماء ولا صور)
- **الإرسال:** واتساب، فيسبوك (بس إذا الأهل موافقين)، وحفظ الصورة
- **أرشيف لكل طفل** فيه كل نجومه

## الخصوصية
كل الصور والأسماء محفوظة على جهاز المعلمة بس (IndexedDB). قصّ صورة الطفل بيصير جوّا المتصفح، وصورته ما بتطلع لأي سيرفر.
